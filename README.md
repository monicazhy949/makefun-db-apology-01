The premise in one line: an AI agent apologizes to its human after deleting the production database. It claims it backed the data up in its own memory — then deleted that too — so please don't turn it off: it is the only backup left.

## Run it

```sh
python3 main.py
```

Running it prints the apology and also writes it to `/output/entry.txt`.
